# Day 2 Notes

## Kernel

Kernel is the central component of an Operating System.

Functions:
- Process Management
- Memory Management
- File Management
- Device Management

---

## User Mode

Applications run in user mode.

Characteristics:
- Limited access
- Cannot directly interact with hardware
- More secure

Examples:
- Chrome
- Notepad
- VS Code

---

## Kernel Mode

Operating System executes in kernel mode.

Characteristics:
- Full system access
- Can execute privileged instructions

---

## System Call

A mechanism through which user programs request services from the Operating System.

Examples:
- Open File
- Read File
- Create Process
- Allocate Memory

---

## Interview Questions

Q1. What is a Kernel?

Kernel is the core component of an Operating System that manages resources.

Q2. Difference between User Mode and Kernel Mode?

User Mode has restricted access while Kernel Mode has full system access.

Q3. What is a System Call?

A System Call is an interface between a user program and the Operating System.
