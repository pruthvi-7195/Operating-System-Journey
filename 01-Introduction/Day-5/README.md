## FCFS Scheduling

FCFS stands for First Come First Serve.

Processes are executed in the order they arrive in the Ready Queue.

Example:

P1 → P2 → P3

## Key Concepts

* Burst Time (BT)
* Waiting Time (WT)
* Turnaround Time (TAT)
