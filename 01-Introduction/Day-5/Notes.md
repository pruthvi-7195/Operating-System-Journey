# Day 5 Notes

## CPU Scheduling

CPU Scheduling determines which process gets CPU time.

Goals:
- Maximize CPU Utilization
- Reduce Waiting Time
- Reduce Turnaround Time

---

## Terms

### Burst Time

Execution time of a process.

### Waiting Time

Time spent waiting in Ready Queue.

### Turnaround Time

Completion Time - Arrival Time

---

## FCFS Scheduling

First Come First Serve.

Characteristics:
- Simple
- Non-Preemptive
- Can cause Convoy Effect

Example:

P1 → P2 → P3
