# Day 4 Notes

## Thread

A thread is the smallest unit of CPU execution.

A process can contain one or more threads.

Example:
- Browser Tabs
- Download Manager

---

## Multithreading

Executing multiple threads simultaneously within a process.

Advantages:
- Better Performance
- Faster Execution
- Improved Responsiveness

---

## Process vs Thread

Process:
- Independent execution unit
- Own memory space

Thread:
- Part of a process
- Shares memory with other threads

---

## Real Life Examples

1. Chrome Browser
2. VS Code
3. Music Player
4. Games

---

## Interview Questions

Q1. What is a Thread?

A thread is the smallest unit of CPU execution.

Q2. Difference Between Process and Thread?

Process has its own memory whereas threads share memory.

Q3. What is Multithreading?

Executing multiple threads concurrently within a process.
