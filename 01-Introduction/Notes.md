# Operating System Notes

## What is an Operating System?

An Operating System (OS) is system software that acts as an interface between the user and computer hardware.

Examples:
- Windows
- Linux
- macOS
- Android

---

## Functions of Operating System

1. Process Management
2. Memory Management
3. File Management
4. Device Management
5. Security Management

---

## Why Do We Need an OS?

Without an operating system:
- Users cannot interact with hardware easily.
- Resource allocation becomes difficult.
- Program execution cannot be managed efficiently.

---

## Types of Operating Systems

### Batch Operating System
Jobs are processed in batches.

### Time Sharing Operating System
Multiple users share CPU time.

### Distributed Operating System
Several computers work together.

### Real-Time Operating System (RTOS)
Provides quick response within fixed deadlines.

Examples:
- VxWorks
- QNX
