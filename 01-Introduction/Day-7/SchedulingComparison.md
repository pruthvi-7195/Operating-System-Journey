# CPU Scheduling Comparison

| Feature | FCFS | SJF | Priority |
|----------|------|------|----------|
| Basis | Arrival Time | Burst Time | Priority |
| Simple | Yes | Moderate | Moderate |
| Starvation | No | Yes | Yes |
| Average Waiting Time | Higher | Lowest | Moderate |
| Real-Time Systems | No | No | Yes |

## Conclusion

FCFS is simple.

SJF minimizes average waiting time.

Priority Scheduling ensures important tasks are executed first.
