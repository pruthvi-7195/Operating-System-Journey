# Day 3 Notes

## Process

A process is a program in execution.

Examples:
- Chrome
- VS Code
- Spotify

---

## Process States

1. New
2. Ready
3. Running
4. Waiting
5. Terminated

Process Flow:

NEW → READY → RUNNING → WAITING → READY → TERMINATED

---

## Process Control Block (PCB)

PCB stores information about a process.

Contents:
- Process ID
- Process State
- Program Counter
- CPU Registers
- Memory Information

---

## Interview Questions

### What is a Process?

A process is a program currently being executed.

### Difference Between Program and Process?

Program:
- Passive entity
- Stored on disk

Process:
- Active entity
- Executing in memory

### What is PCB?

PCB is a data structure used by the Operating System to store process-related information.
