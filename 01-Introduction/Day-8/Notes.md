# Day 8 Notes

## Round Robin Scheduling

Round Robin assigns CPU to each process for a fixed time quantum.

If a process is not completed, it is moved to the end of the queue.

---

## Time Quantum

A fixed amount of CPU time allocated to a process.

---

## Advantages

- Fair Scheduling
- Better Response Time
- Suitable for Time-Sharing Systems

---

## Disadvantages

- Too many context switches if quantum is small.
- Acts like FCFS if quantum is large.

---

## Interview Questions

1. What is Round Robin Scheduling?

2. What is Time Quantum?

3. What happens if Time Quantum is too small?

4. What happens if Time Quantum is too large?

5. Why is Round Robin suitable for Time Sharing Systems?
