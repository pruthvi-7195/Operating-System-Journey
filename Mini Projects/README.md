# CPU Scheduler Simulator

## Overview

This project simulates various CPU Scheduling Algorithms used in Operating Systems.

## Algorithms Implemented

- FCFS
- SJF
- Priority Scheduling
- Round Robin

## Technologies

- Java
- Operating System Concepts

## Learning Outcome

- Understood scheduling algorithms.
- Compared execution orders.
- Practiced Java programming.
- Built a mini Operating System project.
