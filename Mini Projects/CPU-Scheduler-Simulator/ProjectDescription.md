# CPU Scheduler Simulator

A menu-driven Java application that demonstrates the working of various CPU Scheduling Algorithms used in Operating Systems.

## Features

- First Come First Serve (FCFS)
- Shortest Job First (SJF)
- Priority Scheduling
- Round Robin Scheduling

## Technologies Used

- Java
- Object Oriented Programming
- Operating System Concepts

## Learning Objectives

- Understand CPU Scheduling algorithms.
- Compare execution order of different schedulers.
- Strengthen Operating System fundamentals.
- Practice Java programming.
